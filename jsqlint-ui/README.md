
# jsqlint-ui

J-SQLint 前端模块，基于 Vue 3、Vite、TypeScript 和 Element Plus 构建。

## 技术栈

- 前端框架：Vue 3
- 开发语言：TypeScript
- 构建工具：Vite 6
- Vue 编译插件：@vitejs/plugin-vue
- 路由：vue-router 4
- 状态管理：Pinia
- UI 组件库：Element Plus
- 图标库：@element-plus/icons-vue
- HTTP 请求：axios
- 图表：ECharts
- 国际化：vue-i18n
- 样式预处理：Sass
- 类型检查：vue-tsc

## 常用命令

```bash
npm run dev
npm run build
npm run preview
```

## 目录结构

- `src/api`：后端接口封装
- `src/views`：页面级 Vue 组件
- `src/stores`：Pinia 状态管理
- `src/router`：前端路由配置
- `src/assets`：静态资源和样式资源
